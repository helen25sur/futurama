# 🚀 Futurama Universe App
Welcome to the Futurama Universe web application! This project is a dedicated fan portal designed to explore the iconic world, characters, and episodes of Futurama.

[View Live Demo](https://futurama-v2.netlify.app/)

## 📖 About the Project
This is a clean, fast-loading React application built to showcase the Futurama universe. It provides an intuitive interface for fans to browse through their favorite characters and episodes. The project is optimized for performance and responsiveness using Vite.

## Key Features:
  - Character Gallery: A clean layout to view your favorite characters.
  - Episode Guide: A structured list to explore the show's seasons and episodes.
  - Responsive Design: Fully optimized for desktops, tablets, and mobile phones.
  - Fast Performance: Built with Vite for instant hot module replacement and lightning-fast builds.

## 🛠 Tech Stack
  - React — UI Framework
  - Vite — Build tool and dev server
  - React Router — For seamless page navigation
  - CSS/SCSS — For styling and design
  - Netlify — For continuous deployment

## 🚀 Getting Started
To get a local copy of this project up and running on your machine, follow these simple steps:

### Prerequisites
Node.js (v16 or higher recommended)

`npm or yarn`

### Installation
  1. Clone the repository:

```Bash
git clone https://github.com/helen25sur/futurama.git
```

  2. Navigate to the project directory:

```Bash
cd futurama
```
  3. Install dependencies:

```Bash
npm install
```
  4. Start the development server:

```Bash
npm run dev
```
The app will be available at [http://localhost:5173](http://localhost:5173) by default.

### 📦 Build for Production
To create an optimized production build, run:

```Bash
npm run build
```
The output files will be generated in the `dist/` folder, ready to be deployed to any static hosting service.
